> 来源：飞书《ROS2多模态AI搬运小车》→《一、项目章程》

## 一、项目目标

机器人从起始位置出发，通过已建立的环境地图自主导航至 A 取料工位；利用摄像头识别指定物体，机械臂完成抓取；随后自主导航至 B 放料工位，准确放置目标物体，最终返回起始位置或进入待命状态。

整个过程无需人工遥控，允许在故障情况下进行安全干预。

## 二、项目范围

通过两个月的项目式学习，综合运用 ROS 2 通信框架、SLAM 建图与定位、Nav2 自主导航、OpenCV 视觉识别、麦克纳姆轮运动学、嵌入式电机控制、机械臂运动控制及多模块通信技术，完成一套移动机器人自主抓取与转运实验课程，并交付可运行的机器人系统、源代码、设计资料及项目测试报告。

## 五、验收标准

| 验收模块 | 基础验收指标 | 进阶挑战 |
|---|---|---|
| 底盘运动 | 前进、后退、横移、旋转均可稳定执行；稳态轮速误差≤10% | 更高速度与更小误差 |
| SLAM 建图 | 测试区域成功建图、保存并重新加载地图 | 改善地图畸变及重复建图一致性 |
| 自主导航 | 50 次测试≥48 次成功；终点误差≤10cm、角度≤10° | 位置≤2cm、角度≤3° |
| 视觉识别 | 固定光照场景下，100 次识别≥95 次正确 | 支持多目标及不同光照 |
| 机械臂抓取 | 100 次标准物体抓取≥90 次成功 | 抓取成功率≥95% |
| 重复定位 | 初步建议偏差≤±10mm，按机械臂实测能力确认 | ≤±5mm |
| 嵌入式通信 | 10000 帧有效指令测试，正确接收率≥99.9% | 进一步优化响应延迟 |
| 整机业务 | 30 次独立完整任务，成功≥27 次 | 成功率≥95% |
| 安全性 | 急停有效、通信丢失后能安全停止、电源异常可保护 | 故障自恢复 |
| 连续运行 | 通过4小时连续运行测试，无严重故障 | 24小时稳定性测试 |

各岗位对应的验收模块见各自的任务页。

## 十一、六个岗位如何串成一个任务

| 作业阶段 | 主要负责岗位 | 需要完成的事情 |
|---|---|---|
| 用户说“把 A 点的箱子搬到 B 点” | 交互 | 理解需求，生成任务 |
| 接收任务并安排执行顺序 | 系统集成 | 检查条件，启动作业流程 |
| 前往 A 点 | 导航＋底盘 | 规划路线，实际行驶和停车 |
| 找到需要搬运的箱子 | 视觉 | 输出目标位置 |
| 抓起箱子 | 机械臂 | 完成抓取，返回结果 |
| 运送到 B 点 | 导航＋底盘 | 带载行驶，到达放货位置 |
| 放下箱子 | 机械臂，必要时结合视觉 | 完成放置并确认结果 |
| 告知用户任务结果 | 系统集成＋交互 | 汇总状态并反馈 |

> 对你当前阶段，系统集成的流程设计应尽早开始：先约定六个方向如何配合，再让各岗位分别开发。这样每个人都清楚自己要接收什么、输出什么，以及怎样才算完成。
